# 📘 Go Study Guide 

Bem-vindo ao meu repositório de estudos de **Go (Golang)**! 🚀  
Aqui está a organização dos módulos que estou estudando neste curso.

## 📂 Módulos  

1. **Introdução** – Primeiros passos com Go  
2. **Configurando ambiente** – Instalação e configuração do ambiente  
3. **Fundação** – Conceitos fundamentais da linguagem  
4. **Pacotes importantes** – Bibliotecas e pacotes essenciais  
5. **Context** – Gerenciamento de contexto em Go  
6. **Banco de dados** – Conectando e interagindo com bancos de dados  
7. **Packaging** – Organização e empacotamento de código  
8. **Testing** – Estratégias e ferramentas de testes  
9. **APIs** – Construção de APIs RESTful  
10. **Multithreading** – Concorrência e paralelismo  
11. **Manipulando eventos** – Event-driven programming  
12. **Módulos privados** – Gerenciamento de módulos privados  
13. **GraphQL** – Implementação de APIs GraphQL  
14. **gRPC** – Comunicação eficiente entre serviços  
15. **Upload S3** – Armazenamento e upload no Amazon S3  
16. **Cobra CLI** – Construção de CLIs com Cobra  
17. **SQLC** – Geração de código SQL  
18. **UOW (Unit of Work)** – Padrão de unidade de trabalho  
19. **DI (Dependency Injection)** – Injeção de dependências em Go  
20. **Clean Architecture** – Arquitetura limpa aplicada  
21. **Deploy com Docker e Kubernetes** – Implantação de aplicações  

## 🏆 Objetivo  

O objetivo deste curso é aprofundar meus conhecimentos em Go, abordando desde os fundamentos até técnicas avançadas de arquitetura e deploy.  

Se tiver sugestões ou quiser trocar ideias, fique à vontade para entrar em contato! 🚀
